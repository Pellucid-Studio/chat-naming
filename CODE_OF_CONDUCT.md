# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, personal attacks, discriminatory language and publishing other people's private information are not accepted in issues, pull requests or any other project space.

Maintainers may edit or remove comments, close threads and block participants who break these rules.

To report a problem privately, use the [Chat Naming support page](https://pellucid.studio/chat-naming/support/) and mark the message as a conduct report. Reports are handled confidentially.
